# 机智定食 · jizhi-meals

可在 iPhone 主屏幕打开的私人生活手账，支持多食材排餐、月历、学习运动打卡、轻量贴纸、每日文字日记、八套 PNG 分享模板和 JSON 备份。保留草莓牛奶纸张手账风格，纯静态、离线优先，无需账号或苹果开发者账号。

## V1.5 · 让每天记录更顺手

- 食材添加入口移到续航下方、列表旁，底部可连续添加；保存保留整理位置。新增只先填基础信息，用量、备注、保质期等更多设置默认折叠，原能力和已保存内容保留。
- 保留综合预测，新增只看蛋白质与整套食物的主菜续航。优先预留未吃计划、按实际用量与保质期逐午晚餐推算；主菜分项统计实际可覆盖餐数，同一餐的多种蛋白质不重复计顿。切换模式不改库存或餐食。
- 自制便当、公司食堂、面包卡消耗、外食、外卖五个场景仅预填草稿；便当三组可选多种食材并收为自定义常吃模板。任意日期和餐次均可用，保存及已吃仍遵循原库存规则。
- 学习默认日语 / 画画 / 3D建模，运动默认力量训练 / 徒步 / 有氧训练；支持多个类别、可选详情与类别新增、改名、排序、停用。稳定 ID 保留历史归属，月度天数按自然日去重，多项目不重复计天。
- 28 枚贴纸分六类，增加最近与常用入口；每天最多三枚不同贴纸。与全局手账视觉及八套完成美术返工的 PNG 版式一起发布，保持已确认的草莓牛奶、纸纹、波点与马卡龙风格。
- 使用原 `jizhi-meals-v1`，schema 4 兼容旧手账；首次保存先留完整原文到 `jizhi-meals-v1.5-upgrade-backup`，失败不覆盖。新模板、类别、详情与贴纸均可 JSON 备份恢复。

使用指南、验证范围与实际设备限制见 [V1.5 更新说明](V1.5-UPDATE.md)。

## V1.4 · 用月历看见生活

- 餐食记录内可切换日记录、连续虚线月历和日期时间轴；总月历与吃饭 / 运动 / 学习模式使用粉、奶绿、奶紫圆点，按所选月份统计天数。
- 学习运动各自一键打卡 / 取消，详情自愿填写，可补记过去日期；同一天多项活动只计一天。取消保留详情，不设置连续打卡目标或惩罚。
- 每日可选最多三枚内置贴纸，只保存贴纸 ID；日记录与时间轴都能看到。
- 每类两套不同布局：吃饭手账 / 早餐店菜单、暴走小票 / 活力徽章板、自习室笔记 / 图书借阅卡、一天拼贴 / 生活月报。可选日期范围与竖版 / 长图 / 方图，实时预览后下载或系统分享。没有记录的栏目不虚构数据，私人内容默认关闭。
- 继续原本地保存位置，兼容旧 JSON。首次保存前自动保留完整升级前原文；新打卡与贴纸进入 JSON 备份与恢复。详见 [V1.4 更新与数据保护](V1.4-UPDATE.md)。

## V1.2 · 今天的手账与历史月份

V1.0 与 V1.1.1 稳定版本分别保留为本地标签 `v1.0-stable-20261012`、`v1.1.1-stable`。V1.2 在已有数据结构上优化首页、历史月份和布局，详情见 [V1.2 更新说明](V1.2-UPDATE.md)。

- 打开 App 直接进入今天的餐食和日记。左上角「时间轴」用于上下滑动查看历史预览；点日期进入详情，再次打开时间轴会恢复浏览位置。周导航、跳转日期和回到今天保留。
- 生活汇总可用前后月按钮或月份选择器查看任意历史月，支持跨年份。本周、本月为快捷入口；统计与最近记录都按所选范围显示。
- 缩小 Banner，三餐改为横向纸条，库存仍为两列小卡片。保留纸张、胶带、插画与颜文字，历史原始记录不会因切换页面或月份而改变。
- 萌萌颜文字放进时间轴留白、餐食小提示、日记入口和保存提示中，例如 `(｡•ᴗ•｡)`、`(˶ᵔ ᵕ ᵔ˶)`、`(๑•̀ㅂ•́)و✧`。

- 一餐可关联多种食材，各自填写用量；未吃计划只预留，已吃才扣库存。修改已吃记录会返还原用量并扣新用量，删除或撤销会返还全部用量。
- 零食不限每日条数，可填写时间、备注和库存食材；日记、心情和小确幸独立关联日期。
- 生活汇总提供本周 / 本月天数、餐次数量及最近餐食和日记，无评分或强制打卡。
- 分享卡片只在设备上生成真正 PNG，默认隐藏心情、日记、小确幸和餐食备注。生成后点「分享 / 保存图片」使用系统分享，或下载 PNG、长按预览保存。
- 继续使用原本的 `jizhi-meals-v1` 存储位置。读取 V1 记录时只在内存中迁移；首次保存前将完整旧 JSON 留在 `jizhi-meals-v1-migration-backup`，可在设置中导出。迁移不会重新扣减已吃库存。

已批准发布更新后，先在手机导出 JSON 备份，再联网打开网站，让新离线资源下载完成；关闭该网站的所有 Safari 窗口及主屏幕应用后重新打开，使新缓存整体生效。请核对记录，再测试飞行模式。

## 免费发布到 GitHub Pages

1. 登录 GitHub，打开本仓库的 [Settings → Pages](https://github.com/hujizhigululu-beep/jizhi-meals/settings/pages)。手机上看不到 Settings 时，可在 Safari 中请求桌面网站。
2. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
3. 在 **Branch** 选择 **main**，文件夹选择 **/ (root)**，点击 **Save**。
4. 等待 GitHub 完成发布。Pages 设置页会显示发布地址；部署进度可在仓库的 Actions 中查看。
5. 发布成功后打开：https://hujizhigululu-beep.github.io/jizhi-meals/

注意：上述网址只有在 Pages 发布成功后才可使用。仓库文件已上传不代表网站已经上线。

## 安装到 iPhone 主屏幕

建议使用 iOS 15.4 或更新版本。

1. 用 **Safari** 打开已发布的网址，首次打开保持联网。
2. 点击 **分享 → 添加到主屏幕**。较新 iOS 如显示“作为网页 App 打开”，请开启；名称可保留“机智定食”。
3. 点击 **添加**，再从主屏幕上的图标打开。
4. 打开 **我的设置**，等待显示“离线资源已缓存”。之后可开启飞行模式，关闭再打开应用，确认手账仍能显示和操作。

若网站显示 404，请先核对 Pages 设置和部署是否完成，不要把仓库的 github.com 页面当作应用网址。若没有“添加到主屏幕”，先确认正在使用 Safari，并在分享菜单中向下滚动查看。

## 保存与迁移数据

餐食和库存保存在当前设备的浏览器本地，不会自动同步到 GitHub、其他手机或其他浏览器。主屏幕应用与 Safari 中的记录也应在安装后核对。

- 在 **我的设置 → 导出 JSON 备份** 保存到“文件”或 iCloud Drive，并确认文件已保存。
- 更换设备、网站地址，或安装后没有看到原记录时，在原位置导出，再在新位置选择 **导入 / 恢复**。
- 导入会替换整本手账，确认前会显示内容摘要；请先备份现有数据。
- 清理网站数据或删除主屏幕应用可能导致记录丢失，请定期备份。

## 开发与资源

直接使用静态 HTTP 服务托管仓库根目录；正式安装和离线缓存需 HTTPS（本地开发可用 localhost）。

使用 Node.js（当前验证为 Node 24）运行 `npm test` 和 `npm run check`。本地浏览器回归运行 `npm run test:browser`，需要 Node Playwright 与 Chromium；可用 `CHROMIUM_PATH` 指定可执行文件。`UI_ENGINE=webkit npm run test:v14-browser`、`UI_ENGINE=webkit npm run test:ui-browser` 可检查 WebKit 手机尺寸（环境变量写法随终端调整）。独立模板与月历检查为 `test:share-browser`、`test:month-browser`。测试浏览器使用独立数据，不访问用户的真实手账；图片及报告放在忽略目录 `tests/ui-previews/`。

食物插画来自 OpenMoji，授权与逐项来源见 [资源说明](assets/credits.html)。应用图标和牛奶纸盒为本项目原创。
