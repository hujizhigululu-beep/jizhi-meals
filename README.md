基于正式版 V1.5.0（9c41c32）的独立 AI 测试手账。保留草莓牛奶手账、餐食、库存、日记、学习运动、月历、贴纸和 PNG 分享。当前 V1.5.0-ai3.1 增加角色管理、透明头像、四类短评和日记回信区，不做多轮聊天或后台生成。

## 手机测试

1. 在「我的设置」展开「🍓 草莓邮局 · AI 连接实验室」。
2. Base URL 默认 https://www.jiemomo.com/v1，填写独立、低额度测试 Key。邮局会读取中转站 /models，自动选择可用项，支持搜索与选择；不支持该接口时可手动填写。
3. 点击「测试连接」，只发送「你好，请用一句话回复：草莓邮局连接成功」。最多等待 30 秒，可以取消。
4. 查看模型实际文本或失败原因；完成后点击「清除本次密钥」。刷新后重新填写 Key。

Key 只在当前页面内存，不保存到 localStorage、sessionStorage、IndexedDB、JSON 备份或分享图片。请拒绝浏览器和密码管理器保存 Key。前端直连有密钥风险，不要使用正式或高额度密钥。

仅允许 HTTPS，已有 Base 路径后接 /chat/completions，不再添加 /v1；也接受完整 endpoint。模型读取只发送鉴权信息；连接测试只发送固定测试句。来信生成只在点击后发送已预览内容，不使用额外代理、不放宽浏览器安全设置。网络失败可能来自 CORS、TLS、重定向或服务不可达，浏览器不一定能区分。

## 隔离与开发

测试手账从空数据开始，不自动复制正式数据。主数据、升级备份和查看偏好均以 jizhi-ai-test- 命名；缓存以 jizhi-ai-test-shell- 命名。Service Worker 仅处理自身 scope 内同源 GET，AI POST 不进入缓存。Manifest 名称和 ID 独立，资源使用相对路径。手账可离线，连接测试必须联网。

原 JSON 格式兼容，本次实验建议使用测试记录。Node 24 下运行 npm run check、npm test；专项浏览器检查 npm run test:ai-browser 需要开发环境 Playwright（应用无运行时第三方依赖）。

验证与回退见 [AI 测试版交付记录](AI-TEST.md)，插画授权见 [资源说明](assets/credits.html)。

## 角色与 AI 手账贴纸

设置页管理 API、用户资料、多角色、通用文学与各类任务提示词。最原终一、小tt有不同的可编辑默认设定；旧版用户的已有预设逐字保留。角色可新增、复制、停用，自定义角色可确认删除；恢复默认先确认。角色最多100个，每项提示词最多300000字符，AI总文本最多1500000字符，超限拒绝保存，不截断草稿。

在餐食、运动、学习和库存旁点「AI 点评」，在日记下方点「写一封回信」。入口使用全局默认角色，点贴图可临时换人，仅用于一次请求，取消或失败也回到默认角色。发送前显示并允许编辑实际文字；回信的生活类别默认全不选。完整组合已保存的用户人设、角色人设、角色专属或通用文学预设、对应任务与本次记录。120秒超时、可取消，长预设提示上下文未知，不删字。

生成先预览，主动保存后才写入本地。短评使用纸片气泡；同日多封信在日记下方按生成时间排列、可展开全文。保存生成时的角色名称、头像、实际记录快照，不修改原生活记录，也不会随角色或库存变化重写。分享的AI内容默认不勾选，勾选后加入透明贴图与全文，过长时提示逐封分享。原分享未选AI时保持相同图片。

头像支持PNG/WebP/JPG，本地缩到最长边512px，保留透明通道，单张最多200KiB。图片存在独立IndexedDB，资料与收藏存在原AI测试版本localStorage。JSON备份同时携带被引用的头像、用户、角色、短评及来信，不含Key。兼容旧备份，损坏或不完整的新备份拒绝覆盖；首次保存角色新版前留存旧邮局原文。
